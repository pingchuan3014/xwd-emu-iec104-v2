# xwd-emu-iec104-v2

1、帧结构
    TypeID (Type identification)，1个字节；
    VSQ，可变结构限定词，1个字节；
    链路地址（COT）， 也叫传输原因，1个字节；
    oa，originator address，源地址，1个字节，可用于区分客户端；
    COA（Common Address of ASDU）：ASDU通用地址，即ca，也即站点号，占两个字节；
    信息对象地址（IOA），用以识别站点内定义的数据，三个字节；
    信息值。

2、常见传输原因
    1—周期，循环
    2—背景扫描
    3—突发，自发上传
    4—初始化
    5—请求或被请求
    6—激活
    7—激活确认
    8—停止激活
    9—停止激活确认
    0x0A—激活结束
    0x14—响应总召唤
    0x25—响应计数量总召
    0x2C—未知类型的ASDU类型
    0x2D—未知传输原因
    0x2E—未知ASDU公共地址
    0x2F—未知信息对象地址

3、帧分类
    1）U格式为不计数的控制功能类型，用于传输链路控制命令的报文，U格式帧为6字节短帧。
    特征：第3个字节的后两位为11，即(buffer[2] & 0x03) == 0x03
        68 04 07 00 00 00 启动传输激活
        68 04 0B 00 00 00 启动传输确认
        68 04 13 00 00 00 停止传输激活
        68 04 23 00 00 00 停止传输确认
        68 04 43 00 00 00 链路测试激活
        68 04 83 00 00 00 链路测试确认
    2）I格式为信息帧，用于传输数据，捎带确认对方的发送，长度大于6个字节，为长帧。
    特征：第3个字节最低位为0，即(buffer[2] & 1) == 0
    3）S格式为计数的监视功能类型，用于传输对站端确认的报文，长度仅6个字节。无应用数据可传输时，带接受序号确认已经收到的信息。
    特征：第3个字节为0x01，即buffer [2] == 0x01

4、连接层参数
    1）k表示在某一个特定的时间内未被确认的连续编号的I格式APDU的最大数目。
        设置k值后，当未确认的I格式APDU达到k值时，发送方停止发送。
        接收方收到w个I格式的APDU后回复S帧进行确认。k的取值范围是1~32767，w的取值范围应不超过k的2/3。
    2）T0：是控制站与被控站建立连接的超时时间，
        即被控站进入等待链接的状态后，若超过此时间，控制站还没有连接被控站，被控站就主动退出等待链接的状态；默认10s。
    T1：被控站启动U帧测试过程后等待U帧测试应答的超时时间，
        若超过此时间还没有收到控制站的U帧的测试应答帧，就主动关闭TCP链接；默认15s。
    T2：被控站以突发的传送原因向控制站上送了变化信息，
        或以激活结束的传送原因向控制站上送总召唤/电度召唤结束帧后，
        等待控制站S帧的超时时间，若超过此时间还没有收到，就主动关闭TCP链接；默认10s。
    T3：当被控站和控制站之间没有实际的数据交换时，任何一端启动U帧的测试过程的最大时间间隔；规约的缺省时间为20秒；默认20s。

5、常见TypeID
    1）0x01：遥信单点
    3）0x03：遥信双点
    9）0x09：遥测归一化值
    11）0x0B：遥测标度值
    13）0x0D：遥测浮点值
    15）0x0F：累计量
    30）0x1E：带时标单点信息-
    31）0x1F：带时标双点信息-
    34）0x22：带时标遥测归一化值
    35）0x23：带时标遥测标度值
    36）0x24：带时标遥测浮点值
    37）0x25：带时标累计量
    45）0x2D：遥控单点
    46）0x2E：遥控双点
    48）0x30：遥调归一化值
    49）0x31：遥调标度值
    50）0x32：遥调浮点值
    58）0x3A：遥控单点带时标
    59）0x3B：遥控双点带时标
    61）0x3D：遥调归一化值带时标
    62）0x3E：遥调标度值带时标
    63）0x3F：遥调浮点值带时标
    100）0x64：总召唤
    101）0x65：计数量总召唤
    102）0x66：召唤单个IOA
    103）0x67：时钟同步
